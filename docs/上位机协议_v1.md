# SuperCar2 上位机协议 v1（代码实现准则）

更新日期：2026-10-05。本文件是当前通信契约，Emm X42S 及 ROS 方案使用相同的 TYPE 编号。USART2，115200 / 8N1。当前实际接线左地址 01、右地址 02；旧巡线工程的相反映射不沿用。数值运动正方向为车体前进，配置中的 `CAR_LEFT_SIGN` / `CAR_RIGHT_SIGN` 映射为驱动器方向；默认左 +1、右 -1，装车前仍应实测。

## 1. ASCII 调试

每行以 `\n` 或 `\r\n` 结束，命令大写，十进制数字。不要在同一个会话交错发送 ASCII 和二进制；固件根据最近完整命令切换自动回报模式。

| 命令 | 语义 |
| --- | --- |
| `PING` | 返回 `OK PONG`，不续期运动 watchdog |
| `HEARTBEAT` | 续期 300 ms watchdog |
| `MOTOR ENABLE 1` | 请求使能左轮；可带第四参数 `0/1`，默认 1 |
| `MOTOR ENABLE 2 0` | 先停止双轮，再失能右轮 |
| `MOTOR VEL 1 -30 10` | 左轮 -30 RPM，加速度档位 10 |
| `WHEELS 30 30 10` | 双轮原子接受目标，再逐台下发 |
| `MOTOR POS 1 3200 30 10` | 左轮相对当前位置 +3200 脉冲，30 RPM，档位 10 |
| `MOTOR POS 1 -3200 30 10 1` | 左轮绝对坐标 -3200 脉冲；最后参数为模式 |
| `STOP` / `MOTOR STOP 1` | 都停止双轮，清掉运动请求，保持锁轴 |
| `ESTOP` | 停止双轮并锁存急停故障 |
| `CLEAR_FAULT` | 请求停止、解除驱动器保护、失能、重新核验，满足条件后清锁存 |
| `STATUS` / `MOTOR STATUS 1` | 当前缓存的状态、速度、故障、在线、配置确认、反馈年龄 |

位置模式 `0`=相对上一输入目标，`1`=相对坐标零点的绝对位置，`2`=相对当前实时位置（默认）。脉冲数为带符号 int32；默认 1.8°、16 细分时 3200 脉冲/电机圈。此参数由实际驱动器细分决定。

响应 `OK QUEUED` 为请求已接收，须等电机 ACK 和状态确认。错误：`ERR ARGUMENT`、`ERR NOT_READY`、`ERR SAFETY_LOCK`、`ERR BUSY`。`OK RECOVERY` 为恢复流程已接受，随后故障掩码变 0 才算恢复完成；不会自动重新运动。状态变化输出 `EVENT FAULT <mask>`。ASCII 模式不定时发送全部反馈，避免刷屏；用 `STATUS` 查询。

## 2. 二进制帧

```text
AA 55 01 TYPE LEN SEQ PAYLOAD... CRC_LO CRC_HI
```

- `LEN` 仅是 payload 长度，最大 64，总长度为 LEN+8。
- CRC16/MODBUS：初值 FFFF，多项式 A001，反射逐位，CRC 覆盖 `VER TYPE LEN SEQ PAYLOAD`，**不含 AA 55**，低字节先发。测试 `123456789`→4B37。
- payload 所有多字节整数均为**小端**；STM32→电机协议为大端，固件负责转换。
- SEQ 为 uint8。除 STOP、ESTOP、HELLO 外，必须在最近成功请求之后递增，允许 255→0；前进距离 1..127。重复/倒序返回 ACK result 5，不执行，不续 watchdog。
- 失败的请求不推进序号窗口。重新连接后发送 HELLO，再从下一序号发送命令；HELLO 停止并失能，保留故障锁存。
- 每 100 ms 发送心跳或有效速度目标；PING、STATUS、错误帧、重复帧不续期。位置动作只发一次，随后用心跳保活。
- 使能请求仍保留时，即使已 STOP 或轮速为零，也继续心跳；结束会话可明确失能。仅刚上电、未请求使能的空闲状态不要求持续保活。

### 下行消息

| TYPE | LEN | payload（按顺序） |
| --- | --- | --- |
| 01 速度 | 5 | int16 left_rpm、int16 right_rpm、uint8 acc |
| 02 双轮位置 | 12 | int32 left_pulses、int32 right_pulses、uint16 rpm、uint8 acc、uint8 mode |
| 03 停止 | 0 | 无；停止双轮，保持锁轴 |
| 04 急停 | 0 | 无；停止并锁存 |
| 05 使能 | 2 | uint8 addr（01/02）、uint8 enable（0/1） |
| 06 恢复故障 | 0 | 无；异步恢复流程 |
| 10 心跳 | 0 | 无 |
| 11 查询反馈 | 0 | 无；立即排入 80/81 回报 |
| 12 HELLO | 0 | 无；停止、失能、重设接收序号 |

速度上限默认 ±60 RPM，可在配置文件调高；越界拒绝，不静默限幅。位置速度必须 1..60。加速度 0..255，0=直接启动；建议首次用 10。双轮请求先检查两个电机条件，全部通过才接受；驱动器总线实际逐台执行，因此两轮有毫秒级起动差。

### 上行消息

| TYPE | LEN | payload |
| --- | --- | --- |
| 80 状态 | 14 | uint32 stm_tick_ms、uint16 faults；左、右各 4 字节：state、flags、online、config_ok |
| 81 反馈 | 40 | uint32 stm_tick_ms；左、右各 18 字节：int16 rpm、int64 position_ticks、uint32 speed_tick_ms、uint32 position_tick_ms |
| 82 故障变化 | 2 | uint16 faults |
| 83 请求应答 | 2 | uint8 original_type、uint8 result；SEQ 回显请求序号 |

80/81 默认 100 ms 回传，82 在故障变化时回传。遥测序号与下行独立。result：0=已接受，1=参数错误，2=未初始化/未使能/不在线，3=安全锁定，4=忙，5=重复或倒序。ACK 只确认 STM32 接受，不确认物理运动完成。发送队列满时可丢遥测/应答，上位机用状态/时间戳判断，不要为丢失 ACK 重新发送非幂等的相对位置动作。

state：0 INIT、1 DISABLED、2 READY、3 SPEED、4 POSITION、5 STOPPING、6 FAULT。初始化和故障优先级可能使短时状态显示 STOPPING/FAULT；`config_ok`、faults、flags 与时间戳一起判断。

flags 是驱动器 3A 原始标志：bit0=使能，bit1=位置到达，bit2=堵转，bit3=堵转保护；其他位参见驱动器手册。

`position_ticks` 是带方向映射的真实 Emm 驱动器反馈，**65536 ticks/电机圈**，不是控制脉冲数。按驱动器位置差计算里程，使用实际轮径和减速比：

```text
wheel_turns = delta_ticks / (65536 * motor_revolutions_per_wheel_revolution)
wheel_distance_m = wheel_turns * pi * measured_wheel_diameter_m
delta_s = (distance_left + distance_right) / 2
delta_yaw = (distance_right - distance_left) / measured_wheel_base_m
```

STM32 未虚构轮径/轮距，输出原始反馈与采样时间。初次反馈应只建立基线；断电、故障重启、计数回绕或时间戳不连续时重新建立里程计基线。检查 online/config_ok 和反馈年龄，不能把旧反馈当作实时位置。

## 3. 故障掩码

| bit / 十进制值 | 含义 |
| --- | --- |
| 0 / 1 | 软件 ESTOP 或 PB12 低有效急停 |
| 1 / 2 | 上位机超过 300 ms 无有效保活 |
| 2 / 4 | 电机事务超时、运动反馈过期 |
| 3 / 8 | 驱动器堵转/保护、可选报警输入、运动中使能丢失 |
| 4 / 16 | 固件或串口/应答配置不匹配 |
| 5 / 32 | UART 接收错误/溢出、发送错误或 TX 卡住 |
| 6 / 64 | 驱动器拒绝命令、反馈字段不合法 |

所有故障锁存、停止双轮。恢复时输入必须释放，驱动器配置有效、在线，状态/速度反馈新鲜，速度为 0、无堵转保护、已失能。恢复流程失败会保留故障，修正后再次 CLEAR_FAULT。

## 4. Python 参考

`tools/host_link.py` 提供标准库 CRC、frame、Decoder、反馈解码，可用于之后 ROS 串口节点。无硬件时打印帧；指定 --port 才打开串口，需 pyserial。`--type run` 会 HELLO、等待配置、依次使能、每 100 ms 更新速度，最后发送 STOP；速度由用户参数明确指定。

```powershell
python tools/host_link.py --type velocity --left 30 --right 30 --seq 1
python tools/host_link.py --port COM5 --type run --left 30 --right 30 --seconds 3
```

Linux 使用实际 `/dev/ttyS1` 或 `/dev/ttyUSB0` 替换 COM5。run 示例要求两轮在线；单轮联调先使用 ASCII。

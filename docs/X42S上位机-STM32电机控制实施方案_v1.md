# X42S 上位机—STM32 电机控制实施方案（当前实施版）

更新日期：2026-10-05。对应 `SuperCar2` 的实际代码、`SuperCar2.ioc` 和 `Core/Inc/car_config.h`。本方案的下位机软件及 3 模块重构已完成，并通过 ARM 编译及完整模拟回归，真实电机与整车仍待联调。

## 1. 当前控制链路

```text
香橙派 5 UART1（26 Pin 物理 5 TX / 3 RX）
              │ 3.3 V TTL，TX/RX 交叉，共地
              ▼
STM32 USART2：PA2 TX / PA3 RX
              │ car_uart：上位机协议与收发
              ▼
car_motor + car_control：电机状态与保护
              │
STM32 USART1：PA9 TX / PA10 RX
              ├── X42S / Emm 左轮，地址 01
              └── X42S / Emm 右轮，地址 02
```

CH343 可替代香橙派连接 USART2，用于桌面调试。两个上位机 TX 不同时连接 PA3。USART3、I2C、PWM 和外部编码器当前未启用。

电机链路采用厂商支持的 X42S TTL 多机接口。PA9→驱动器 R/A/H，PA10←驱动器 T/B/L，所有设备共地。RS485/CAN 版本需要相应收发器及软件适配，当前实现不包含这些接口。

## 2. 已实现的下位机模块

| 文件 | 职责 |
| --- | --- |
| `main.c` | CubeMX 硬件初始化；调用 `CarControl_Init` / `CarControl_Poll` |
| `car_uart.c/.h` | 两路 UART 中断收发、缓冲、非阻塞 TX、异常恢复；ASCII/二进制协议、CRC、序号门禁、ACK 与遥测 |
| `car_motor.c/.h` | Emm 帧和回包、配置门禁、双轮状态、共享总线事务、优先停止及异步恢复 |
| `car_control.c/.h` | 主循环调度、PB12 急停、PB13/14 可选报警、300 ms 保活、故障锁存、PC13 LED、独立看门狗 |
| `car_config.h` | 地址、方向、限速、周期、单轮模式、保护开关 |

代码位于本工程 `Core/Inc`、`Core/Src`，已加入 Keil 工程。旧 SuperCar 的状态分层和周期思想作为参考，未移入其直流 PWM/编码器控制逻辑。

## 3. 当前引脚和参数

| 引脚 | 当前功能 | 实际配置 |
| --- | --- | --- |
| PA9 / PA10 | USART1 电机总线 | 115200 / 8N1，IRQ 1,0 |
| PA2 / PA3 | USART2 上位机 | 115200 / 8N1，IRQ 1,0 |
| PB12 | ESTOP_IN | 输入上拉，接 GND 触发，默认参与保护 |
| PB13 / PB14 | DRIVER_FAULT_L/R | 输入上拉，默认不参与保护 |
| PC13 | STATUS_LED | 推挽低速，低有效 |
| PA13 / PA14 | SWD | 保留 |
| PD0 / PD1 | HSE | 8 MHz 晶振，PLL×9，系统 72 MHz |

GPIO 已在 .ioc 补齐，由 CarControl_Init 内部的板级函数实际初始化；没有使用 EXTI。SysTick 提供 1 ms 时间基准。独立看门狗由板级模块启动，标称约 1 s，调试暂停时冻结。

配置文件默认：左右地址 1/2，方向 +1/-1，限速 ±60 RPM，加速度档位 10，双轮模式，PB12 保护开启，可选报警输入关闭。单接左轮时将 `CAR_SINGLE_MOTOR_TEST` 改为 1 后重新编译。方向、细分、轮径、轮距和减速比须实测；下位机不填入虚构底盘尺寸。

## 4. 驱动器初始化门禁

分别设置电机地址 01、02、Emm 固件、UART、115200、固定 6B 校验、Response=Receive；关闭定时主动上报、缩小 10 倍输入、上电自动运行及自动回零。首次先做空载校准。

启动流程：先逐台发送立即停止，再对每台读取 1A 选项、42 配置、3A 状态、35 速度，最后发送失能并等待 ACK。全部初始化完成且电机在线，才允许使能；实际使能确认后才接受运动。

代码核验 Emm 42 回包为 33 字节、21 参数，并检查 UART、115200、地址、6B、Receive，以及 1A 的 Emm/无缩放选项。配置不匹配或回包超时锁存故障，不自动改写驱动器永久参数。

## 5. Emm 命令与反馈单位

| 功能 | 电机帧（十六进制） |
| --- | --- |
| 使能 | Addr F3 AB enable 00 6B |
| 速度 | Addr F6 dir rpm_H rpm_L acc 00 6B |
| 位置 | Addr FD dir rpm_H rpm_L acc pulses[4] mode 00 6B |
| 立即停止 | Addr FE 98 00 6B |
| 选项 / 配置 | Addr 1A 6B / Addr 42 6C 6B |
| 实时速度 / 位置 / 状态 | Addr 35 6B / Addr 36 6B / Addr 3A 6B |
| 解除驱动器保护 | Addr 0E 52 6B |

电机帧多字节字段为大端。控制命令 02 ACK 表示驱动器接收，E2/EE 表示拒绝。正常调度每次只有一个等待回包的事务，左右轮逐台执行；当前使用 snF=0，不使用广播同步启动。

速度命令与反馈为整数 RPM。位置命令为细分后的脉冲数：1.8°、16 细分时 3200 脉冲/圈。位置反馈为每电机圈 65536 ticks；两者不能混用。位置 mode：0 相对上一输入目标，1 绝对坐标，2 相对当前实时位置，ASCII 默认 2。

位置动作只下发一次；ACK 超时则停机锁存，不能因 ACK 丢失重发相对位置。到位用后续 3A bit1 判断。

## 6. 调度与安全

| 项目 | 当前数值 / 行为 |
| --- | --- |
| 主循环 | 持续非阻塞调度，收到目标即可更新 |
| 速度刷新 | 每轮约 50 ms |
| 状态 / 速度查询 | 每轮约 50 ms |
| 位置查询 / 上位机遥测 | 约 100 ms |
| 电机事务超时 | 20 ms，之后总线安静 25 ms |
| 运动状态 / 速度过期 | 超过 250 ms 停机 |
| 上位机保活 | 使能请求或运动活动期间，300 ms 无有效保活则锁定 |
| UART TX 卡住 | 超过 20 ms 终止 TX 并锁存 |
| 故障停止重试 | 速度非零或反馈不新鲜时，约 100 ms 重发 |

这些是软件调度阈值，实际反馈周期受总线延迟影响。上位机每 100 ms 发送心跳或有效速度命令；PING、STATUS、重复帧、错误帧不续期。位置动作后用心跳保活。

停止取消待执行目标和事务等待，已开始的 UART 帧先发完，再依次发送两个立即停止帧；不等左轮停止 ACK 才停止右轮。正常 STOP 保留使能锁轴，零速反馈确认后回到 READY/DISABLED。即使已 STOP，只要仍有使能请求，仍应继续心跳或明确失能。

急停、驱动器保护、UART 错误、电机失联、配置不符均锁存故障。CLEAR_FAULT 请求异步恢复：输入释放、停止、解除保护、失能、核验新鲜零速及无保护，满足条件后清故障；随后必须重新使能和下发运动。不会自动恢复旧目标。

串口断线或 CPU 卡死时无法保证串口停止作用到电机，硬件急停应有独立的动力/使能停止路径；独立看门狗复位后重新执行启动停止/失能。

## 7. 上位机接口

ASCII 用于初次联调：PING、HEARTBEAT、MOTOR ENABLE、MOTOR VEL、MOTOR POS、WHEELS、STOP、ESTOP、CLEAR_FAULT、STATUS。每行换行结束，OK QUEUED 表示 STM32 接受请求，电机状态另行确认。

正式帧：

```text
AA 55 01 TYPE LEN SEQ PAYLOAD CRC16_LO CRC16_HI
```

CRC16/MODBUS 覆盖 VER 到 PAYLOAD，payload 多字节数值小端。消息编号固定为：

- 01 左右速度，02 左右位置，03 停止，04 急停，05 单轮使能，06 恢复；
- 10 心跳，11 查询，12 HELLO（停止、失能、重置接收序号）；
- 80 状态，81 带采样时间的真实速度/位置，82 故障变化，83 接受应答。

完整长度、字段、去重和故障码以 [上位机协议 v1](上位机协议_v1.md) 为准。ROS base_driver 将 cmd_vel 按实测底盘参数转换成左右 RPM；odom 从反馈位置差计算。
